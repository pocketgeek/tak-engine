# Source provenance template

Copy this record for every new artifact; leave missing evidence explicitly UNKNOWN.

- Source ID:
- Artifact role (installer, installed file, primary document, mirror, recollection):
- Original filename / archive-member path:
- Claimed product, version, language, distribution:
- Claim source (URL or containing artifact ID):
- Retrieval URL and redirects / local supplied location:
- Retrieval date (UTC):
- Original publication date (UNKNOWN if not established):
- Observed bytes:
- Observed SHA-256:
- Independently published hash / algorithm / citation:
- Independent match verified? What exactly matched?
- Signature/authentication evidence (or NONE):
- Extraction tool version, commit, binary hash and exact command:
- Parent artifact ID and member/container path:
- Transformations or filters applied:
- Completeness limits (payload vs installed state, skipped files, partial extraction):
- Permitted evidence classification and claims it supports:
- Claims it does NOT establish:
- Local storage location (do not commit original assets):

A mirror timestamp is not a release date. A matching mirror hash establishes byte
identity with that listing, not a publisher signature. An installation containing
Iron Plague files is not automatically an unmodified Iron Plague distribution.
